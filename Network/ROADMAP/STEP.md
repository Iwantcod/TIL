# Network 학습 STEP

## 학습 원칙
1. Chapter 1부터 Chapter 8까지 순서를 고정하고 건너뛰지 않는다.
2. 체크는 섹션 단위로 진행하며, 완료 즉시 체크박스를 갱신한다.
3. 각 주차는 요약 섹션까지 마친 뒤 30~60분 복습한다.
4. 이해가 부족한 섹션은 다음 주차 시작 전에 재학습 후 보완한다.
5. 1차 목표는 순서 기반 완주와 개념 연결이며, 심화 실습은 2차에서 확장한다.

## 학습문서 생성 일반화 계획 (CH1~CH8 공통)

### 파일명 규칙
- 챕터 학습문서는 `CH1.md`부터 `CH8.md`까지 고정한다.
- 각 파일은 해당 챕터의 세부 목차(예: `1.1~1.8`)를 동일 순서로 유지한다.

### 챕터별 생성 파이프라인 (5단계)
1. 목차 고정: 교재 챕터 목차를 기준으로 섹션 구조를 먼저 확정한다.
2. 공식 출처 수집: IETF RFC, IBM, Cisco 공식 문서만 수집한다.
3. 교차검증: 핵심 정의/수치/프로토콜 동작을 출처 간 교차 확인한다.
4. 템플릿 작성: 섹션별 `학습목표-핵심개념-심화 포인트-오해 포인트-체크 질문-한 줄 요약`을 채운다.
5. 품질 체크: 각주, 순서, 누락 여부를 검증 후 반영한다.

### 공통 품질 게이트
- 목차 누락 없음, 목차 순서 오류 없음.
- 핵심 주장에는 근거 각주가 존재함.
- 참고 링크는 공식 URL이며 유효함.
- 요약 섹션은 신규 주장 없이 기존 근거를 재정리함.

### 진행 연동 규칙
- `CHn.md` 완성 직후 `STEP.md`의 해당 챕터 섹션 체크를 갱신한다.
- 체크는 섹션 단위(`n.x`)를 우선으로 하며, 필요 시 주차 단위 완료를 함께 표시한다.
